# 🚀 Autonomous AI Business Salesman Agent System

An enterprise-grade, high-converting AI Sales Closer & Lead Qualification system built with Python FastAPI, SQLite, modern Tailwind CSS Dashboard, and autonomous BANT negotiation intelligence.

---

## 🌟 Top High-Demand Features

1. **Active Sales Psychology & BANT Qualification**:
   - Qualifies Budget, Authority, Need, and Timeline directly in customer chat.
   - Automatically adapts tone between English, Urdu, Hinglish, and Hindi.

2. **Master Objection Handling**:
   - Handles price resistance (*"Bohat mehnga hai"*), competitor comparisons (*"XYZ company is cheaper"*), trust issues (*"Where is the proof/guarantee?"*), and procrastination (*"Baad mein sochenge"*).

3. **Autonomous Action Tools**:
   - **Meeting & Demo Scheduler**: Books appointments directly into the calendar.
   - **Quotation Generator**: Generates instant PDF/Text formal proposals with custom discount codes (`CLOSENOW`, `FIRST10`).
   - **CRM Lead Pipeline**: Real-time Kanban board (New Lead ➔ Qualified ➔ Demo Booked ➔ Proposal Sent ➔ Won / Lost).

4. **1-Click Website Embed Widget**:
   - Embed your AI Salesman on WordPress, Shopify, Webflow, or custom sites with a single `<script>` tag.

5. **Optional External LLM Integration**:
   - Works 100% autonomously out-of-the-box.
   - Optionally connects with Google Gemini 1.5/2.0 or OpenAI GPT-4o keys configured directly from the dashboard.

---

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
pip install fastapi uvicorn pydantic python-dotenv requests httpx jinja2
```

### 2. Run the System
```bash
python run.py
```

### 3. Open the Dashboard
Visit `http://localhost:8000` in your web browser!
